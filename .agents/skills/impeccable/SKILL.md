# Impeccable Design Skill

This skill provides an award-winning design director's judgment to build exceptional frontend interfaces, eliminating generic AI templates and slop.

## Core Directives
1. **No AI Slop / Generic Templates:** Avoid centered cards with default grey shadows, overused purple gradients, and lifeless layouts.
2. **Design Language & Visual Elevation:** Use intentional typography pairings, rich authentic color palettes (e.g. lacquer red, gold leaf, silk white), subtle elevation, and glassmorphism.
3. **Micro-interactions & Responsive Polish:** Smooth transitions, responsive breakpoints, tactile feedback, and accessible contrast.
4. **Cultural Integrity for Heritage UIs:** When handling traditional motifs (Việt Phục), honor historical truth, dynastic origins, and ceremonial rules while injecting contemporary freshness for younger generations.
